# Arcade Hours schedule

Edit the seven entries at the top of `js/schedule.js` to update stream titles and hours. Times use 24-hour Eastern time (`America/New_York`), automatically following EST/EDT. Leave start/end empty for an off day. Use same-day afternoon/evening streams; overnight streams are not supported.

The website schedule is independent of Twitch Extension Configuration Service. Changing the Twitch extension does not change this site.

`js/script.js` contains Current Cabinet details. Social links and profile text are in `index.html`.

The local-time selector converts stream times and their start dates. Off days remain Eastern calendar dates. Countdown reflects planned hours, never actual live status.

The page is static HTML/CSS/JavaScript and is published from the repository root.
